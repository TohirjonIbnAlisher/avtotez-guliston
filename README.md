# Avtotez Guliston

Avtomaktab o'quvchilarini haydovchilik guvohnomasi nazariy imtihoniga (20 savoldan 18+) tayyorlash uchun veb-ilova.

## Tuzilma

- `frontend/` — Angular ilova (landing page + o'quv platformasi)
- `backend/` — NestJS API (savollar, biletlar, foydalanuvchilar, statistika)
- `data/` — test savollari uchun shablonlar va import fayllari

## Texnologiyalar

- **Frontend:** Angular
- **Backend:** NestJS (TypeScript)
- **Ma'lumotlar bazasi:** PostgreSQL
- **Hosting (tekin):** Render (backend), Neon/Supabase (DB), Vercel/Netlify (frontend)

## Boshlash

Har bir papka (`frontend`, `backend`) o'zining README faylida ishga tushirish bo'yicha ko'rsatmalarga ega.
